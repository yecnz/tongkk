개념을 연결하고, 헷갈리는 지점을 찾고, 이유를 설명해 보세요.
같은 자료 안에서 네 단계가 하나의 학습으로 이어집니다.

하나의 개념을 따라가 보세요 “퀵 정렬은 언제 빠르고, 언제 느려질까?”

  1. 01 요약

    흩어진 개념을
    서로 연결해요

    핵심과 세부 내용을 나눠 읽고, 개념의 관계와 차이를 비교해요. 어디에 쓰이는 개념인지 맥락을 잡습니다.

    이렇게 이해해요퀵 정렬은 평균 O(n log n).
    하지만 분할이 치우치면 최악 O(n²).

    공부하는 방식에 맞춘 네 가지 요약

    • 일반 요약핵심 개념과 전체 흐름을 빠르게 파악
    • 강의 노트설명·예시·주의점을 차근차근 정리
    • 마인드맵개념을 펼치고 접으며 관계를 시각적으로 확인
    • 치트시트정의·공식·비교표를 한눈에 찾아보기
    요약에서 더 할 수 있는 일

    여러 자료·페이지 범위·집중할 내용을 선택해 요약하고, 마인드맵의 개념을 튜터 질문으로 이어갈 수 있어요. 체험에서는 펼치기·접기·확대·축소·PNG 저장도 사용할 수 있어요.

    네 가지 요약 체험하기
  2. 02 퀴즈

    헷갈리는 부분이
    답을 고를 때 드러나요

    읽었던 내용을 직접 떠올려 답해 보세요. 정답과 내 답을 비교하면 어떤 조건을 놓쳤는지 알 수 있어요.

    이렇게 발견해요“퀵 정렬은 항상 O(n log n)이다.”
    평균과 최악을 구분해서 답할 수 있나요?

    자료를 바탕으로, 내 수준에 맞게

    • 문제 유형 선택객관식·OX·단답형·주관식으로 확인
    • 범위와 난이도 설정공부한 자료와 필요한 수준에 맞춰 문제 생성
    • 채점과 해설내 답·정답·이유를 함께 살펴보기
    • 문항별 이동이전 문제와 풀이 결과를 다시 확인
    퀴즈에서 더 할 수 있는 일

    실제 서비스에서는 문항 수(5·10·15·20개), 출제 페이지와 집중할 내용을 고를 수 있어요. 주관식 모범답안·피드백과 시간 제한 시험 모드도 제공해요.

    이 페이지에서는 객관식·OX 예시 3문제를 직접 풀어볼 수 있어요.

    평균과 최악 구분해 보기
  3. 03 튜터

    왜 그런지 묻고,
    내 말로 설명해요

    해설에서 막힌 부분을 질문하고, 예시를 바꿔가며 이유를 확인해요. 답을 아는 데서 한 걸음 더 나아갑니다.

    이렇게 질문해요“분할이 한쪽으로 치우치면
    왜 O(n²)가 되는지 예로 설명해줘.”

    내 자료에 대해 이어서 질문하기

    • 개념 설명어려운 용어를 쉬운 말과 예시로 풀어보기
    • 비교와 추가 질문비슷한 개념의 차이를 대화로 좁혀가기
    • 오답에서 이어가기틀린 이유를 묻고 다음 확인 질문으로 연결
    • 수식과 표설명 속 수식·목록·비교 내용을 읽기 쉽게 확인
    튜터에서 더 할 수 있는 일

    실제 서비스에서는 원본·요약 문맥을 바탕으로 질문해요. 본문 선택·마인드맵·오답에서 질문을 연결하고, 이미지 첨부·답변 복사·대화 기록도 이용할 수 있어요.

    튜터 체험은 샘플 자료에 맞춰 준비한 예시 답변으로 동작해요.

    튜터에게 이유 물어보기
  4. 04 재확인

    다시 풀면서
    이해했는지 확인해요

    설명을 읽은 뒤 다시 답해 보세요. 맞혔는지와 함께 왜 그 답인지 설명할 수 있는지도 확인합니다.

    이렇게 내 지식으로 남겨요“항상은 아니야. 균형 잡힌 분할은 빠르지만,
    치우친 분할이 반복되면 O(n²)가 돼.”

    한 번의 풀이에서 다음 복습까지

    • 결과와 풀이 확인점수와 문항별 정답·오답을 함께 확인
    • 다시 풀기답을 새로 고르며 이해한 내용을 재확인
    • 오답 노트실제 서비스에서 틀린 문제를 모아 복습
    • 요약으로 돌아가기남은 빈틈을 같은 자료에서 다시 연결
    복습에서 더 할 수 있는 일

    실제 서비스에서는 과목별 오답을 모아 다시 풀고, 취약점·더 공부할 내용·암기 포인트·공부 방법을 분석해요. 오답을 튜터에게 보내 설명과 확인 질문을 이어갈 수 있어요.

설명 학습의 네 단계 살펴보기
  1. 1
    범위를 정하고, 직접 설명

    처음 배우기·수업 후 회상 중 방식을 고르고, 자료 범위와 목표 시간에 맞춰 시작해요.

  2. 2
    평가와 근거 확인

    평가 기준별로 확인됨·빠짐·수정 필요·판단 보류를 살피고, 내 설명과 원문을 비교해요.

  3. 3
    막히면 힌트로 보완

    단계별 힌트와 모범 설명을 참고하고, 수정한 설명을 다시 평가받을 수 있어요.

  4. 4
    확인 문제, 그리고 다음 복습

    설명 뒤에는 문제로 확인해요. 도움을 받은 보완과 시간이 지난 뒤 혼자 떠올린 기록을 구분해요.

내 강의자료로 요약·질문·퀴즈·설명 학습을 하고, 암기 카드와 복습으로 다시 확인하는 AI 학습 도우미예요. 학습 코스·계획·통계로 다음 공부까지 이어갈 수 있어요.

설명 학습과 튜터는 어떻게 다른가요?

튜터는 내 자료에 대해 질문하며 설명을 듣는 대화예요. 설명 학습에서는 내가 먼저 개념을 설명하고, 평가 기준과 원문 근거에 따라 피드백을 받아요. 힌트로 보완하고 확인 문제를 풀며 이해한 내용을 점검합니다.

어떤 자료를 올릴 수 있나요?

PDF, PPT·PPTX, 이미지, Word(.docx) 문서와 텍스트·Markdown 자료를 사용할 수 있어요. 글자가 흐리거나 복잡한 표·수식이 많은 자료는 변환 결과를 원본과 함께 확인해 주세요.

이 페이지에서 학습을 시작할 수 있나요?

원본·요약·퀴즈·튜터부터 설명 학습, 카드, 코스, 계획, 통계, 외부 연동, 메뉴바까지 실제 UI와 예시 데이터로 둘러볼 수 있어요. 각 기능 설명 아래에서 바로 조작해 보세요. 변경 내용은 이 체험에만 적용되고, AI 답변과 외부 연동 결과는 준비된 예시예요. 내 자료와 학습 기록을 저장하려면 ‘내 자료로 시작하기’로 이동해 로그인해 주세요.

요약과 퀴즈는 어떻게 연결되나요?

강의자료를 올려 요약을 만든 뒤 같은 자료로 퀴즈를 생성할 수 있어요. 틀린 문제는 오답 노트에 모아 다시 풀고, 학습 캘린더와 계획으로 다음 공부를 이어갈 수 있어요.

AI가 만든 내용을 그대로 믿어도 되나요?

AI가 생성한 요약이나 답변에는 오류가 있을 수 있어요. 중요한 개념과 수치는 원본 강의자료와 비교하고, 이해가 잘 되지 않는 부분은 튜터에게 추가로 질문해 보세요.
