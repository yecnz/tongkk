각 기능별 검증 후 커밋·푸시한다. 비밀값, 답변·원문 전문은 운영 계측 로그에 남기지 않는다.
추가 DB 변경은 새 마이그레이션과 schema.sql에 함께 반영하고 로컬 DB 테스트로 검증한다.

AI 계측: SQLite 영속 파일(AI_USAGE_DB), 최근 30일 소유자별 조회. 모델 내부 자동 재시도를 끄고 호출별 집계한다. 단가 미설정·토큰 미수신은 비용 미확인으로 표시한다.

환경 검증: 잠금 파일로 생성한 별도 Python 3.12 가상환경에서 backend 228개·고정 평가 17개 통과. 로컬 Docker 데몬이 꺼져 있어 이미지 빌드는 실행하지 못했으며, CI에 Linux 빌드·도구·health 검사를 추가했다.

최종 검증:
- Frontend: 152개 테스트, TypeScript, ESLint(기존 Quiz 훅 경고 4개), 프로덕션 빌드 통과. 기존 큰 청크 경고는 유지.
- Backend: 잠금 파일로 설치한 별도 Python 3.12 환경에서 232개 테스트 통과.
- DB: 로컬 PostgreSQL(WASM) 학습·복습 67개 검사 및 요약 마이그레이션 이력·중복 저장 검사 통과.
- 고정 샘플: 17/17 통과, API 호출 0. 실제 모델 정확도·학생 성과로 해석하지 않는다.
- Linux x86_64: 잠금 파일의 바이너리 패키지 설치 dry-run 통과. Docker 데몬 부재로 이미지 빌드·실행은 미검증.
- 브라우저 실제 클릭 검사는 기존 사이트 접근 제한으로 수행하지 않았으며 컴포넌트 흐름 테스트로 검증했다.

운영 반영 전 미적용 Supabase 마이그레이션 적용·서버 재배포가 필요하다. 적용 명령과 실행 환경은 server/README.md 참고.
12개 변경을 기능별 커밋으로 feature/system-imporove에 푸시한다. 다른 작업에서 작성한 미추적 기획 문서는 포함하지 않는다.
