# 학습 기능 화면과 사용 흐름

`Tongkk_학습기능_화면과_사용흐름.docx`는 8개 기획 기능과 확장 기능을 21개 화면, 24쪽으로 설명하는 Word 문서입니다. 각 화면에 실제 서비스의 진입 위치, 사용 순서, 결과 및 상태 의미를 적었습니다.

## 캡처 기준

- 작성일: 2026-11-23, 기능 구현 기준 커밋: `aa60ba3`.
- 실제 구현 컴포넌트를 로컬 미리보기에서 렌더링하고 브라우저 UI로 조작해 캡처했습니다. 화면의 학습·평가·연결 상태는 설명용 데이터입니다.
- 복습 관리, 복습 풀이, 설명 개선은 구현된 페이지를 사용했습니다. 대시보드·자료·통계·마이페이지·캘린더는 필요한 기능 컴포넌트를 `LearningLayout` 안에 모은 주변 화면입니다. 전체 운영 페이지와 주변 배치가 다를 수 있습니다.
- 자료 본문과 학습 메이트 대화, 모델 평가 및 외부 계정의 연결 상태는 예시입니다. 실제 OAuth 승인이나 외부 자료 가져오기 성공을 증명하는 캡처가 아닙니다.
- 원본 JPEG는 `screenshots/`에 보관했습니다. 문서에는 Word의 이미지 자르기로 주요 영역을 확대했으며 원본 파일을 수정하지 않았습니다.
- 실제 백엔드·사용자 계정·외부 서비스·모델 호출 없이 로컬에서 준비했습니다. 별도 미리보기 설정만 사용하며 운영 앱의 인증 코드를 수정하지 않았습니다.

## 화면 다시 열기

저장소 루트에서 다음 명령을 실행합니다. 기존 개발 서버와 별개로 `127.0.0.1:5177`에서만 열립니다.

```sh
node node_modules/vite/bin/vite.js --config scripts/learning-guide-preview/vite.config.mjs
```

미리보기 전용 주소:

- `/`, `/review?tab=today`, `/review?tab=issues`
- `/learn/review/review-process`
- `/summary`, `/summary?panel=preparation`
- `/stats?view=concepts`, `/stats?view=graph`
- `/mypage?panel=review`, `/mypage?panel=calendar`, `/calendar`
- `/mypage?panel=drive`, `/mypage?panel=notion`
- `/learn/session-process/revisions/revision-process`

미리보기 전용 쿼리 `panel`은 문서 캡처에 필요한 영역을 고르는 값이며 실제 앱의 메뉴 주소로 추가한 기능이 아닙니다. 일부 조회·제출·저장 동작만 메모리에서 재현합니다. 새로고침하면 메모리 상태가 초기화되지만, 실제 컴포넌트가 저장한 브라우저 초안은 남을 수 있습니다. 외부 계정 연결 버튼은 외부로 이동하지 않고 안내를 표시합니다.

## 문서 다시 생성하기

`guide-content.json`에 제목·진입 위치·단계·결과·그림 영역이 있습니다. `python-docx`와 `Pillow`를 제공하는 문서용 Python 환경에서 실행합니다.

```sh
python scripts/learning-guide-preview/build-guide.py
```

문서 글꼴은 Noto Sans KR입니다. 렌더러가 임시 사용자 환경을 사용할 때는 해당 글꼴의 실제 디렉터리를 Fontconfig에 추가해야 한글을 확인할 수 있습니다. 문서 생성 후에는 반드시 페이지 이미지로 렌더링하여 24쪽 모두 확인합니다. 최종본은 모든 페이지의 한글·그림·단계·페이지 번호와 목차 쪽수를 점검했습니다.
