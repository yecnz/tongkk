# 고정 샘플 품질 회귀 검사

프로젝트 루트에서 실행:

```sh
server/.venv/bin/python server/scripts/evaluate_quality.py --output logs/quality-report.json
```

API 호출 없이 현재 서비스의 점수 정규화·퀴즈 검증·피드백 근거 검증과 요약 형식 검사를 실행한다. 실패 시 종료 코드 1을 반환한다. 보고서에는 반복 문단·없는 페이지·미완성 코드 블록, 잘못된 정답 키, 경계 점수 판정 변화, OCR 오염에 따른 인용 거부 여부를 기록한다.

샘플은 직접 작성한 합성 자료다. 난이도별 집계는 고정된 샘플 수와 정답 키 일치 수이며 실제 학생 정답률이나 모델 정확도가 아니다. 정답 키는 사람의 기준 답안과 비교하고, 현재 구조 검증만으로 의미가 틀린 정답을 탐지할 수 있다고 주장하지 않는다.

실제 품질 평가는 익명화한 허가 자료에 대해 사람이 원문·기준 답안·오답 원인을 표기한 뒤, 같은 입력의 반복 모델 응답을 별도 수집해야 한다. 모델·프롬프트·원문 버전과 AI 사용량을 함께 기록한다. 검수한 응답을 fixtures에 추가하되 기대 결과를 구현 결과에 맞추어 자동 변경하지 않는다. 원문 의미 정확도와 난이도별 실제 풀이율은 해당 표본이 확보된 뒤 측정한다.
